# Classic Reimagined Install Guide for 1.20 and newer
You can download Classic Reimagined from [Modrinth](https://modrinth.com/resourcepack/classic-reimagined-10s), [CurseForge](https://www.curseforge.com/minecraft/texture-packs/classic-reimagined) and this GitHub repository, the way to install it is pretty simple, you must download both the resource pack and the [dependency pack](https://modrinth.com/project/ULU4JTr0), if you're using OptiFine, make sure you've downloaded the mod [here](https://optifine.net), and make sure it's up to date to run the latest features from this resource pack.
